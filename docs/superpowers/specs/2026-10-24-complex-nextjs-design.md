# Сложный Next.js пример

Пользователь просит готовый сложный интерактивный пример; продолжаем реализацию без повторных согласований согласно ранее данному разрешению.

Выбран сценарий корпоративной заявки, все данные локальные. Одна RHF форма: company, headquarters, contacts[].phones[], branches[].departments[].members[], preferences. FormBuilder slots показывают явно заданные поля; массивами управляет нативный useFieldArray. Вложенные hook-компоненты привязаны ключом к пути, чтобы remount после перемещения родителя не оставлял hook на старом имени. shouldUnregister=false сохраняет значения.

Моковый API: Promise с задержкой, страны/города/сотрудники, поиск, ошибка по специальному запросу. Hook игнорирует результат устаревшего запроса. Смена страны очищает только выбранный город, при восстановлении не происходит скрытого сброса.

Панель управления: reset seed/empty/current baseline, setValue, resetField, trigger, setError/clearErrors, getValues; live JSON значений, touched/dirty, ошибки без DOM refs и результат последней отправки. Persistence/local: новый versioned key; восстановление и отправка блокируют UI. Пользователь может удалить черновик.

Изменения только example и документации, без расширения ядра. Native controls Ant Design: text, textarea, number, select, checkbox; независимые карточки массивов, адаптивный layout.

Альтернатива — большой автоматический список полей, но он хуже показывает управление глубокой структурой. Автоматический array renderer не добавляется.
