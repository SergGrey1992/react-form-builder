# Проверка сложного Next.js-примера

24 октября 2026. Изменения ограничены примером и его тестовой инфраструктурой; ядро библиотеки не изменялось.

- 11 тестов примера: Promise справочники, поиск и ошибка API, stale results, retry, свежие default values и безопасное отображение errors без DOM refs.
- Интеграционные проверки: смена порядка филиалов с сохранением вложенных данных, добавление отделов/сотрудников, копирование филиала, перестановка контактов с телефонами, setValue/resetField, скрытые поля, server errors и nested submit.
- Пустые contacts/branches/phones/departments/members валидируются rules.required. Независимый reviewer выявил, что один minLength не запрещает пустой массив; исправлено и покрыто регрессионными тестами.
- Next.js production build с SSR успешно собирается; typecheck пройден.
- Основная библиотека: прежние 24 теста, strict type tests, ESLint и сборка проходят.
- В браузере: страна очищает город и загружает новый справочник, setValue меняет значение и dirty, отправка блокирует форму и возвращает снимок всей структуры.
- Ant Design 5 / React 19: подключён официальный compatibility patch, предупреждение на интерактивные эффекты устранено.

Решения: нативный useFieldArray, path-key remount вложенных hooks, синхронный refreshStructure только для реестра конфигурации; единственный источник значений — RHF. UI loading селектов не меняет RHF disabled. Root Vitest ограничен core tests, пример запускает свой отдельный test suite; CI включает оба.
