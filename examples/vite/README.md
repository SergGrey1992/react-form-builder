# Vite example

В этой папке: `npm ci && npm run dev`. Пример устанавливает библиотеку версии `0.1.0` из npm, отдельная сборка библиотеки не требуется.
`npm run build` проверяет TypeScript и собирает production bundle.

Показаны автоматическая login-форма с Zod и async submit, регистрация со слотами, вложенный путь address.city и кастомный range control без дополнительного адаптера.
